# aap-juce-altar: Altar on Android

It is a port of [iamlamprey/altar](https://github.com/iamlamprey/altar/) to [Audio Plugins for Android](https://github.com/atsushieno/aap-core) using [aap-juce](https://github.com/atsushieno/aap-juce).

Altar is a plugin that brings in NAM (Neural Amp Modeller). This port brings them to Android.
